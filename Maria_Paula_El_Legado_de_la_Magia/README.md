# María Paula: El Legado de la Magia

## Cómo ejecutar el juego localmente

Para evitar restricciones de seguridad CORS del navegador con módulos ES6, ejecuta un servidor local básico:

### Opción 1: Con Python (Recomendado)
Abre la terminal en la carpeta extraída y ejecuta:
```bash
python -m http.server 8000
```
Luego abre en tu navegador: `http://localhost:8000`

### Opción 2: Con VS Code Live Server
1. Abre la carpeta en Visual Studio Code.
2. Haz clic derecho en `index.html` -> **Open with Live Server**.
